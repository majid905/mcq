# MCQ এক্সাম প্ল্যাটফর্ম — Claude Code-এর জন্য স্পেক প্যাক

এই প্যাকে আছে Claude Code দিয়ে পুরো প্ল্যাটফর্ম বানানোর জন্য যা যা লাগবে: Flutter অ্যাপ (Android + iOS), Next.js স্টুডেন্ট ওয়েব, Next.js অ্যাডমিন প্যানেল আর MySQL-এর উপর NestJS API। ওয়েব আর অ্যাপ **একই সময়ে** বানানো যাবে।

## কীভাবে ব্যবহার করবেন

**দুজন মিলে কাজ করলে** নিচের ধাপের বদলে `docs/09-TEAM-SPLIT_bn.md` অনুসরণ করুন।

1. একটি খালি git রিপো বানিয়ে সব ফাইল ফোল্ডার কাঠামো ঠিক রেখে রুটে কপি করুন।
2. `[App Name]` আর `[Domain]` জায়গায় আপনার ব্র্যান্ড নাম ও ডোমেইন বসান।
3. রিপোর রুটে Claude Code খুলে `prompts/00-foundation.md` পেস্ট করুন। Phase 0 শেষ হওয়া পর্যন্ত অপেক্ষা করুন — `pnpm dev`, `pnpm mock` চলবে, ওয়েব ও অ্যাপে gallery পেজ দেখা যাবে।
4. পরের প্রতিটি ধাপে **তিনটি** Claude Code সেশন (বা git worktree) খুলুন: একটায় API, একটায় ওয়েব, একটায় মোবাইল প্রম্পট (`10/11/12`, `20/21/22`, তারপর `30`, `40`-এর ট্র্যাকভিত্তিক অংশ)। API তৈরির সময় ওয়েব ও অ্যাপ mock সার্ভারে কাজ করবে, তাই কেউ কারো জন্য বসে থাকবে না।
5. প্রতিটি চেকপয়েন্টে শেষ হওয়া ফিচার mock থেকে আসল API-তে সুইচ করে e2e টেস্ট চালান।
6. শেষে `prompts/50-hardening.md` দিয়ে লোড টেস্ট, সিকিউরিটি ও লঞ্চ।

## ওয়েব আর অ্যাপ একরকম থাকার নিয়ম
- API বদলাতে হলে আগে `openapi.yaml` বদলান, তারপর `pnpm contract:gen`।
- রং/স্পেসিং/ফন্ট বদলাতে শুধু `design/tokens.json`, তারপর `pnpm tokens:gen`।
- একই স্ক্রিন রুট, একই স্ট্রিং কি (ARB ↔ next-intl JSON), একই কম্পোনেন্টের নাম।
